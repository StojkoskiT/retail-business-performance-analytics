# Retail Business Performance Analytics

This project analyzes retail business performance using SQL Server and Power BI.

The goal is to clean, transform, analyze, and visualize sales data in order to support business decision-making.

## Tools Used

- Microsoft SQL Server Management Studio 22
- SQL Server
- Power BI Desktop
- VS Code
- GitHub
- SourceTree

## Project Goals

- Build a SQL Server database
- Clean and analyze retail sales data using SQL
- Create business KPIs
- Build a professional Power BI dashboard
- Document the full workflow on GitHub

## Business Questions

- What is the total revenue?
- What is the total profit?
- Which products and categories perform best?
- Which regions generate the most sales?
- What are the monthly sales trends?
- Which customer segments are most valuable?
